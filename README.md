# Test 1

Local music player for Android.

- Plays only audio stored on the device (MediaStore, primary shared storage)
- Playlists
- Artwork and lyrics fetched once when available, then cached on device
- Smooth word-by-word synced lyrics
- Liquid Glass UI via [Kyant0/AndroidLiquidGlass](https://github.com/Kyant0/AndroidLiquidGlass)

Built with Kotlin, Jetpack Compose and Media3. The debug APK is produced by the GitHub Actions workflow.
